# Motes
A simple and intuitive math note taking app

## Features
- Keyboard-only input
- Symbols, Powers, Fractions, Parentheses, Sin
- Nesting
- Caret Navigation
- Selection (clamped to current row/slot)
- Delete
- Clean rendering
- Export AST to json
- New Rows

## Planned features
- Mouse selection
- Copy/paste
- LaTex parsing
- Undo/redo
- More symbols support
